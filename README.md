# DSTR

This repository provides the prediction maps used in the main benchmark comparison of DSTR.
The source code will be released upon acceptance of the manuscript.

## Prediction maps

DSTR was trained and evaluated at 384 × 384 with random seed 2026.
The archives contain 8-bit grayscale PNG prediction maps saved at the original annotation size.
Each map uses the corresponding test image stem as its filename.
